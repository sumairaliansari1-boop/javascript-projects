# Weather App 🌦️

A simple Weather App built using HTML, CSS, and JavaScript.

## Features
- Search weather by city name
- Display temperature
- Show feels-like temperature
- Display humidity
- Show weather conditions
- Weather icons using OpenWeatherMap API

## Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API
- OpenWeatherMap API
