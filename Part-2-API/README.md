# Shopping Cart Manager – API Version

This is the second version of my Shopping Cart Manager project. In the first version, I worked with static products. In this version, I integrated the Fake Store API to fetch and display products dynamically.

I built this project to improve my JavaScript skills and get more practical experience working with APIs.

## Features

- Fetch products from the Fake Store API.
- Display product images, names, and prices dynamically.
- Add products to the shopping cart.
- Increase product quantity when adding the same product again.
- Calculate individual subtotals and the total price.
- Remove individual products from the cart.
- Clear the entire cart.
- Save cart data using LocalStorage.
- Restore cart items after refreshing the page.
- Toggle between Light Mode and Dark Mode.
- Save the selected theme using LocalStorage.
- Responsive layout for different screen sizes.

## Technologies Used

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Make sure you have an internet connection so products can load from the API.
